统一规则

Web 不再单独推断一套状态，而是读取 Service Core 的状态和事件。所有按钮动作也调用 Service Core：scan_now、render_run、preview_cleanup、approve_confirmations、reject_confirmations。

收益

  • 人和 AI 看到同一套状态
  • 删除确认集中管理
  • 问题排查看事件和日志即可
  • 后续可自然加多源和开机启动

暂不做

  • 公网访问
  • 多用户权限系统
  • 复杂素材库管理
  • 云端队列
