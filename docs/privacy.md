# 隐私说明

Venus 默认在本地保存项目配置、录像工作副本、音频中间文件、转录文本、AI 判断、发布物料和成片。扫描、升级和重新处理不会修改原录像。

以下配置可能把数据发送到第三方服务：

- 使用云端语音识别：向用户配置的 ASR 服务发送处理所需的音频。
- 使用云端 AI 服务：发送完成分析和审阅所需的转录文本、候选片段和上下文；不会因此上传原录像文件。

失败日志默认使用 `redacted` 模式，隐藏 prompt、payload 和模型响应正文。调试时可以在 `live-clipper.toml` 中改为：

```toml
[privacy]
failure_log_mode = "full"
```

不要公开分享包含真实转录或 API 响应的 `work/logs` 文件。
