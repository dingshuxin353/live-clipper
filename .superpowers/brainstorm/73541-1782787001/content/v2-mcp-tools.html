V2：MCP 工具边界

MCP 不是第二套业务逻辑。AI 通过 MCP 调用 Service Core，所有动作都进入同一套状态与事件日志。

MCP 调用关系
AI Agent
Codex / Claude / Cursor
MCP Server
thin adapter
Service Core
state + actions
AI asks tools; MCP validates parameters; Service Core performs or rejects actions.
R

Read tools

get_service_status, list_runs, get_run_detail, get_run_log, get_review_package

S

Safe action tools

scan_now, start_run_for_source, write_selected_clips, render_run, preview_cleanup

D

Explicit-confirm tools

stop_service, delete_clip, cleanup_confirm。V2 默认可以不开放，或要求宿主确认。

V2 推荐边界

先开放 Read tools + Safe action tools。删除类能力仅保留 preview，不做 confirm 删除。这样 AI 能完成审阅和渲染，但不会误删文件。
