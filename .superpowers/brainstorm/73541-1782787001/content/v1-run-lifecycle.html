V1：Run 生命周期与恢复

服务的核心不是“跑命令”，而是可靠维护每个录播从发现到成片的状态。

Run 状态机
discovered
发现候选录播
staging
复制到 input
processing
pipeline 后台运行
needs_review
等待 selected_clips
rendering
自动渲染
rendered
成片完成
failed：任何阶段失败都保留错误、日志路径、可恢复建议，不删除源文件。
去重依据
source_id
source_path
file_size
mtime
optional short_hash
恢复策略
服务重启时读取 state
pid 不存在则重新判断 run 文件状态
codex_brief 存在则进入 needs_review
selected_clips 存在但无 clips 则 render

建议的状态文件

work/service/service.json 记录服务进程状态；work/service/runs.json 记录源文件到 run 的索引；work/service/events.jsonl 记录可追踪事件。现有 work/automation_state/*.json 可继续作为兼容层。
