# 资源与配置

本文描述当前开发分支。真实供应商模型、完整短片处理与播放仍需验收；以下配置说明不代表已经发布。

## 先添加资源，再分配项目

在“资源”中添加本机语音识别、云端语音识别、AI 模型或 Claude Code 本地审阅。每项资源独立保存名称、模型、服务地址、用途和凭据，同一供应商可以添加多项配置。同名资源也有独立身份。

AI 资源提供火山方舟、通义、GLM、Kimi 预设，也可选择自定义 OpenAI-compatible 服务。先选供应商，再填账号可用的模型标识；通义还需明确地域和业务空间。点击“获取模型列表”才会查询服务，查询失败可手填。候选列表不代表用途验证通过。

“验证用途”使用内置内容检查实际结构化输出，可能产生费用，不发送用户录像。本机识别模型需先完成下载和完整性检查，再验证识别能力。模型下载支持 ModelScope 或 Hugging Face；处理录像时不会隐式下载模型。

未准备好的资源可以保存，供稍后继续配置。新项目或未启用项目可保留未完成的分配，开始处理前必须准备好必需用途。已启用项目取消必需资源后保持启用状态，但新处理会阻塞。

项目分别选择语音识别、内容分析和 AI 审阅。审阅可明确选择“复用内容分析”，也可使用独立资源。共享资源的更改会影响引用它的项目的新记录；已排队和正在处理的记录保留原修订。

## 保存、修复与删除

编辑草稿保留在本机，未提交密钥只留在当前表单内存。离开或重启后需要重新输入。更改服务地址、模型或参数会使旧验证结果失效；验证失败的更改不能覆盖原本可用的配置。保存响应丢失时，界面会查询原操作，避免重复添加。

失败记录从问题详情进入原资源修订。只有原账号、端点、地域、业务空间和模型身份不变时，才能验证并修复原凭据，随后重新检查并继续。换模型或换服务请显式新建重跑。项目当前配置不会替换失败记录的身份。

资源详情直接提供删除入口。有项目、排队记录、运行记录或准备任务占用时不能删除；可恢复失败记录的影响需先确认。默认保留本机模型。勾选清理只适用于独占、无占用的 Venus 管理模型文件，外部模型、录像和成片不会被清理。部分清理失败可以重试。

## 应用设置

“设置”只管理术语表路径、调度时区与检查间隔、处理超时和审阅候选上限等实际消费的应用参数。录像目录、输出目录和定时规则在项目中修改；模型连接在资源中修改。保存应用设置不会改写资源凭据。

原 TOML 与 `.env` 是升级转换的输入。已有项目的有效配置会转换成具名资源并留下备份；缺少新用途验证证据时显示待准备，不自动下载、调用模型或更换付费服务。新处理不再回退到全局模型默认值。

内置 Codex CLI 已移除。实际使用它的项目需要重新选择审阅资源；仅残留未生效字段的模型直连配置不会被切换。历史成片和审阅材料保留，身份不明的旧记录不能直接继续。
