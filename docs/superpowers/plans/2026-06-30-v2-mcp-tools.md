# V2 MCP Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build V2 MCP tool functions as a thin adapter over the V1 local service core.

**Architecture:** Service Core remains the only state owner for runs, events, and confirmations. `mcp_tools.py` exposes structured read/action functions that validate inputs, call `service.py`, and return bounded dictionaries suitable for an MCP server wrapper. Destructive-intent tools only create pending confirmations.

**Tech Stack:** Python 3.11, pytest, existing `live_clipper.service`, existing selection validation and rendering helpers.
