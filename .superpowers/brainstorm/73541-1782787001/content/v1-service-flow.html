V1：常驻服务内核

第一版目标：用 CLI 自管进程替代外部定时任务，让本地服务持续推进 run 生命周期。

服务主循环
1. Scan Source
按配置扫描 NAS 录播源
2. Stable Check
确认文件年龄和大小稳定
3. Stage
复制到 input，记录 source fingerprint
4. Pipeline
后台执行 pipeline 到审阅包
5. Lifecycle
等待选择，自动 render，cleanup 预演
CLI 控制面
live-clipper service start
live-clipper service stop
live-clipper service status
live-clipper service logs
状态与日志
work/service/service.pid
work/service/service.json
work/service/events.jsonl
work/automation_state/*.json

V1 不做

MCP 工具、Web 控制台重构、launchd 安装、自动删除文件、多录播源完整 UI。V1 只把常驻服务跑稳。
