服务行为
定时任务
服务未运行时不会执行定时任务。任务支持立即执行、暂停和启用。老用户已有的审阅检查不会自动改成 AI 自动审阅；需要时可把任务动作改为 AI 自动审阅，并在下方明确启用 AI 审阅。

创建 / 编辑任务

默认模板：每周录播扫描（周日 00:00）和每周审阅检查（周日 12:00）。
AI 审阅
AI 审阅只会生成选片结果。删除、清理和确认仍需要你在确认页处理。默认不会静默启用，请确认环境可用后再打开。
高级配置
修改 Web host/port 后，需要手动重启 Web 控制台命令本身才会生效。
